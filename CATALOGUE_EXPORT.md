# Catalogue Excel séparé

Lancer `python3 -m pip install XlsxWriter && python3 scripts/export_catalogue.py`.

Le fichier de sortie `Configuration_Catalogue.xlsx` comporte All, catégories, Inventaire, Budget, Tableau de bord et Guide. Il préserve `Configuration.xlsx` modifié manuellement. Les moyennes 10/20 offres restent vides tant qu'elles ne sont pas sourcées.
