# Marketplace V1

Un fichier `LST-XXXXXXXXXXXX.json` par annonce, créé uniquement par l'interface. Les prix `paid_price` et `shipping_paid` sont séparés des prix du vendeur et des offres. Les achats comptent dans le suivi Marketplace seulement avec statut `purchased` et montant payé connu. Ne pas recopier les dépenses dans le catalogue sans réconciliation ultérieure.
